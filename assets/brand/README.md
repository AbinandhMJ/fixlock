# fixlock brand

The **Commit Lock**: a padlock whose shackle is a git line with a commit on top, and a check mark for "fixed".

| File | Use |
|---|---|
| `fixlock-logo.svg` / `.png` | Logo for light backgrounds |
| `fixlock-logo-dark.svg` / `.png` | Logo for dark backgrounds |
| `fixlock-mark.svg`, `fixlock-mark-dark.svg` | Mark alone, light / dark backgrounds |
| `fixlock-icon.svg`, `fixlock-icon-512.png`, `-192.png` | App icon (rounded square) |
| `fixlock-icon-small.svg`, `fixlock-icon-48.png` | Small icon: no commit dot, thicker strokes |
| `favicon.svg`, `favicon-32.png`, `favicon-16.png` | Browser tab: padlock shape only |
| `fixlock-avatar.svg`, `fixlock-avatar-512.png` | npm / GitHub / social avatar |
| `social-preview.png` (1280×640) | GitHub social preview, link cards |

All text is outlined, so the SVGs look the same without fonts installed.

**Colors:** Ink `#0E1116` · Paper `#F4F6F0` · Lime `#B8F23A` · Muted `#A3ADB8` (on ink) / `#4B5563` (on paper). Use lime for shapes, not for text on light backgrounds.

**Type:** Space Grotesk Bold (wordmark, −0.045em tracking) · JetBrains Mono (taglines, commands).

**Don't:** recolor the mark outside these colors, stretch it, add effects, or put the lime body on a light background.
