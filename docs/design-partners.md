# Become a fixlock design partner

We're looking for **10 engineering teams** that use AI coding agents on real code to run fixlock with us for a month, and help shape what it becomes.

## Is this you?

- A team of **3 or more developers** shipping to production.
- You use **Claude Code, Cursor, Copilot, Codex, Windsurf** or similar on that code, at least some of the time.
- You've seen a fixed bug come back, or worry that you will, when an agent or a teammate "simplifies" code they didn't write.
- Your code is on **GitHub, GitLab or Bitbucket**. Any language.

## What you get

- **Setup with us** on a 30-minute call: we lock your most important past fixes with you (`fixlock discover` finds them in your git history), and wire up your agents and CI.
- **Direct support** from the people building it, with fixes and changes for your team first.
- **A say in the roadmap**: the paid team features (org-wide policies, audit history, a dashboard across repositories) get built around what you need.
- **Free throughout the program**, and a founding-partner discount on any paid plan after it.

## What we ask

- Use fixlock on **at least one active repository for 4 weeks**.
- A **20-minute check-in every two weeks**: what it caught, what got in the way, what you'd pay for.
- **Honest feedback**, especially when something is wrong or annoying.
- Optionally, permission to share **anonymised results** (for example "caught 3 regressions in a month").

fixlock is open source and runs on your machines and in your CI; the hosted GitHub App stores none of your code ([how it works](security.md)). It's tested against [36 ways an agent could try to get past it](adversarial.md).

## Apply

**[Open a design-partner application](https://github.com/AbinandhMJ/fixlock/issues/new?template=design_partner.yml)**: it takes two minutes. We reply within two working days.

The application is a public GitHub issue, so leave out anything confidential. If you'd rather talk privately, say so in it and we'll arrange a call.
